# Inventario Frontend

Frontend React + TypeScript + Vite para el sistema de gestión de inventario.

## Instalación

```bash
npm install
```

## Desarrollo

```bash
npm run dev
```

## Build

```bash
npm run build
```

## Variables de entorno

Copiar `.env.example` a `.env` y configurar:

```
VITE_API_URL=http://localhost:3000
```
